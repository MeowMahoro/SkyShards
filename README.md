# SkyShards

[🌐 Live App](https://meowmahoro.github.io/SkyShards/)

SkyShards is a website for the Hypixel Skyblock attribute fusion system.

## Features
- **Fusion planner** — calculates the fastest / cheapest way to fuse into any target shard, using live Bazaar prices
- **Custom rates** — set your own per-shard costs and override recipes to match your local market
- **Inventory aware** — plans around shards you already own to minimize what you need to buy
- **Arbitrage scanner** — scans every fusable end product for craft-vs-buy spreads, with a full cost breakdown
- **Recipe browser** — look up fusion recipes by input or output shard, with search and filters
- **Fusion graph** — an interactive visual map of the entire fusion network
- **Always up to date** — fusion data refreshes automatically and Bazaar prices are pulled live from Hypixel
- **Clean and responsive** — a modern UI that works great on desktop and mobile

## Getting Started
To run locally:
```sh
pnpm install
pnpm run dev
```
